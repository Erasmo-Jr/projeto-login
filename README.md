# 🔐 Projeto Login

Este é um projeto de tela de login desenvolvido com HTML e CSS, com foco em layout moderno, responsividade e boas práticas de estruturação.

## 🚀 Acesse o projeto
👉 https://erasmo-jr.github.io/projeto-login/

## 💻 Tecnologias utilizadas
- HTML5
- CSS3

## 🎯 Objetivo
O objetivo deste projeto foi praticar a criação de interfaces de login, trabalhando principalmente:
- Estruturação com HTML
- Estilização com CSS
- Responsividade para diferentes dispositivos

## 🧠 Aprendizados
Durante esse projeto, pratiquei:
- Organização de layout
- Uso de media queries
- Estilização moderna de formulários
- Boas práticas de HTML e CSS

## 📌 Observação
Este projeto é apenas visual (front-end), não possui integração com back-end ou sistema de autenticação.

## 📈 Evolução
Este projeto faz parte da minha jornada como desenvolvedor. Futuramente, pretendo criar versões mais completas com:
- Validação com JavaScript
- Integração com back-end
- Sistema de autenticação
